# Telegram-бот распознавания речи

Принимает голосовые сообщения, кружки и аудиофайлы, возвращает текст. Работает
через наш собственный сервис распознавания — узбекский, русский, английский,
казахский, киргизский.

## Как включить

1. Создайте бота у [@BotFather](https://t.me/BotFather): `/newbot`, задайте имя,
   получите токен.
2. Впишите токен в `.env` рядом с остальными:

   ```
   SPEECH_TELEGRAM_BOT_TOKEN=123456:AA...
   ```

3. Поднимите сервис:

   ```
   docker compose up -d speech-bot
   ```

## Настройки

| переменная | по умолчанию | что делает |
|---|---|---|
| `SPEECH_TELEGRAM_BOT_TOKEN` | — | токен от BotFather. Заведите **отдельного** бота: `TELEGRAM_BOT_TOKEN` уже занят интеграцией Agentic OS |
| `TELEGRAM_ALLOWED_IDS` | пусто | список Telegram-id через запятую; пусто — бот открыт всем |
| `TELEGRAM_RATE_PER_HOUR` | 60 | сколько записей один человек может прислать за час |
| `BOT_DEFAULT_LANG` | uz | язык по умолчанию: uz, ru, en, kk, ky, auto |

**Про доступ.** Пока `TELEGRAM_ALLOWED_IDS` пуст, распознавать может любой, кто
найдёт бота, — а считает это процессор вашего сервера. Для внутреннего
использования впишите туда id сотрудников: свой можно узнать у
[@userinfobot](https://t.me/userinfobot).

## Что умеет

- голосовые, кружки, аудиофайлы, документы со звуком и видео (берётся дорожка);
- `/lang` — переключение языка распознавания, запоминается для каждого
  пользователя отдельно;
- длинный текст приходит файлом, а не обрезается;
- к записям длиннее нескольких фраз прикладываются субтитры `.srt` с таймкодами.

Ограничение в 20 МБ на файл — со стороны Telegram, обойти его бот не может.
