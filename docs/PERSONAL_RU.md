# Personal в Agentic OS

`Personal` — персональный рабочий центр пользователя. Он не заменяет
операторские панели Creator/Admin и не показывает обычному пользователю
состояние всей инфраструктуры.

## Что работает сейчас

- Ежедневный брифинг на основе реальных личных задач и ожидающих подтверждений.
- Быстрое создание личной задачи.
- Личные задачи и заметки, изолированные по `user.id`.
- Настройка языка, часового пояса, рабочего фокуса и стиля MILA.
- Генерация и синхронизация персонального `SOUL.md` с Obsidian.
- Очередь подтверждений Hermes для Creator/Admin.
- Состояние единого web/mobile аккаунта.
- Полный перевод Personal и общей оболочки на русский, английский и узбекский.
- Адаптивный интерфейс для desktop и узкого окна браузера.

## Язык интерфейса

Переключатель `RU / EN / UZ` находится в верхней панели и на экране входа.
После авторизации выбранный язык сохраняется в серверном профиле пользователя,
поэтому применяется на другом браузере и доступен мобильному приложению через
тот же `/api/onboarding`.

Словарь интерфейса находится в `assets/js/i18n.js`. Новую надпись нужно
добавлять одним ключом сразу во все три секции: `ru-RU`, `en-US` и `uz-UZ`.
Компоненты получают текст через `t("ключ")`, а даты — через `localizedDate()`.
Язык MILA переключается вместе с языком профиля; активный голосовой звонок не
перезапускается и получает новый язык в следующей сессии.

## Разделы

### Сегодня

Показывает текущий фокус, загрузку, личные задачи, последние заметки,
подтверждения агентов и состояние источников данных.

### MILA и SOUL

Хранит персональные параметры ассистента. После сохранения сервер обновляет:

- `Agentic OS/People/<user_id>.md`
- `Agentic OS/People/<user_id>/SOUL.md`

MILA, Hermes и другие агенты получают этот контекст с сервера. В `SOUL.md`
нельзя сохранять пароли, API-ключи и другие секреты.

### Память

Обычный пользователь видит только собственные заметки. Creator/Admin может
отдельно открыть общую Obsidian Library и её граф.

### Подтверждения

Creator/Admin может одобрить или отклонить опасное действие Hermes. Обычный
Member не получает доступ к общей операторской очереди.

### Аккаунт

Показывает роль, рабочее пространство, язык и состояние синхронизации MILA.
Web и мобильное приложение используют одну серверную учётную запись.

## API

`GET /api/personal` возвращает только данные текущего авторизованного
пользователя:

- `account`
- `profile`
- `briefing`
- `tasks`
- `notes`
- `approvals`
- `soul`
- `sources`

Запрос поддерживает web cookie и мобильный bearer-токен. Личные задачи и
заметки продолжают изменяться через `/api/member/*`, настройки SOUL — через
`/api/onboarding`.
