# MFA в Agentic OS

Двухфакторная защита доступна только аккаунтам Creator и Admin. Обычные
Member/Viewer продолжают входить по email и паролю.

## Включение

1. Откройте `Настройки → Безопасность`.
2. В блоке `Двухфакторная защита` введите текущий пароль.
3. Нажмите `Настроить MFA`.
4. Отсканируйте QR-код в Google Authenticator, Microsoft Authenticator,
   1Password или Authy.
5. Введите текущий шестизначный код.
6. Сохраните восемь recovery-кодов вне Agentic OS.

Секрет TOTP и recovery-коды не сохраняются в открытом виде. TOTP-секрет
зашифрован AES-256-GCM ключом, производным от серверного `SESSION_SECRET`.
Recovery-коды хранятся как HMAC-отпечатки и каждый работает только один раз.

## Вход

После правильного пароля Agentic OS не создаёт сессию сразу. Он выдаёт
пятиминутный challenge и просит:

- шестизначный код приложения-аутентификатора; или
- один неиспользованный recovery-код.

Один TOTP нельзя повторно применить в том же временном окне. Web и mobile API
используют один challenge-механизм. Экран MFA в MILA Android должен быть
проверен и подключён на следующем этапе production-теста мобильного клиента.

## Управление

В `Настройки → Безопасность` можно:

- увидеть число оставшихся recovery-кодов;
- заменить recovery-коды после подтверждения действующим кодом;
- отключить MFA после подтверждения кодом.

Отключение MFA завершает все сессии пользователя и требует нового входа.
Удаление аккаунта также удаляет его MFA-конфигурацию.

## Аварийное восстановление

Сначала используйте recovery-код. Если потеряны и устройство, и все
recovery-коды, сброс разрешён только оператору с SSH-доступом к серверу:

```bash
cd /home/admilana/agentic-os
docker compose stop agentic-os
docker compose run --rm agentic-os node scripts/mfa-reset.mjs creator
docker compose up -d agentic-os
```

Для Admin вместо `creator` указывается его `usr_...` ID. Перед сбросом создайте
резервную копию. Команда не показывает TOTP-секреты и не меняет пароль.

Нельзя менять `SESSION_SECRET` без подготовленной миграции: он подписывает
сессии и защищает зашифрованные MFA-секреты.
