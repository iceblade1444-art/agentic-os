# Studio в Agentic OS

Studio объединяет три рабочих отдела:

1. **Дизайн** хранит коллекции и модели, материалы, цвета, себестоимость, цену,
   прогноз спроса и состояние от идеи до выпуска.
2. **Медиа** хранит кампании и очередь создания изображений и видео.
3. **Аналитика** объединяет тренды, конкурентов, масс-маркет, собственные продажи
   и клиентские сигналы в объяснимые рекомендации по ассортименту.

## Рабочий маршрут

```text
Scout → аналитические сигналы → решение по ассортименту
      → Design model → Scribe brief → Reach → Higgsfield MCP
      → review → campaign → результаты продаж → Analytics
```

Каждая генерация создаётся в Media и получает реальную задачу Hermes Kanban.
Reach выполняет её через Higgsfield и возвращает URL результата. Claude можно
подключать для доработки идеи, сценария или промпта, но он не является обязательным
мостом.

## Higgsfield

- Официальный MCP URL: `https://mcp.higgsfield.ai/mcp`
- Авторизация выполняется через аккаунт Higgsfield и OAuth, API-ключ не нужен.
- Кредиты списываются с существующего плана Higgsfield.
- Секреты и OAuth-токены нельзя сохранять в Studio, Kanban, Obsidian или Git.

Одно ручное действие после развёртывания: добавить URL в MCP-настройках Hermes,
войти в Higgsfield и подтвердить OAuth. После этого Media ставит задачу Reach,
который использует прямое подключение.

## Ответственность агентов

- **Hermes**: декомпозиция, зависимости, подтверждения, финальная проверка.
- **Scout**: источники, тренды, конкуренты, рынок и уверенность данных.
- **Scribe**: брифы, сценарии, подписи и локализация RU/EN/UZ.
- **Reach**: кампании, каналы, метрики и генерации Higgsfield.
- **Dev**: интеграции данных, автоматизация, тесты и инфраструктура.

## Границы подтверждения

Пользователь подтверждает расход кредитов, публикацию, рекламный бюджет, запуск
кампании и перевод модели в производство. Агент не считает результат готовым без
проверяемого артефакта или URL.
