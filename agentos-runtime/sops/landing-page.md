# Landing Page SOP

## Purpose
Create a simple local landing page from a business goal.

## Inputs
- Business type.
- Target audience.
- Core offer.
- Desired CTA.
- Brand voice.

## Steps
1. Write a short project brief.
2. Draft page sections:
   - Hero
   - Problem
   - Solution
   - Services/features
   - Process
   - CTA
3. Implement as a standalone `index.html` unless a framework is required.
4. Keep styling embedded for portability in the MVP.
5. Verify the file exists and contains required sections.
6. Save QA report.

## Required sections
- Hero headline
- Subheadline
- Primary CTA
- Services/features
- Process or how it works
- Final CTA

## Validation
- File exists.
- HTML parses well enough for browser preview.
- Required section text is present.
- No fake testimonials or fabricated metrics.
